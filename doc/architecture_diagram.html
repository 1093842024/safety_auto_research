③ 双循环 + 元循环 + MEA + 程序级岛模型编排时序

内循环做研究 → 外循环（layer_11）约束审计 Accept/Refine/Restart → 元循环（layer_09）自递归改进（冻结验证器 + 可证伪 + 回滚）；2026-08-05 新增 MEA（Manage-Execute-Audit）控制循环包裹，以及 OpenRSI 程序级岛模型（四算子 + IslandModel）作为并行的"程序进化"通道。

只读独立检查，completion/integrity/state-update findings；必须异模型/异后端（require_different_from） run_mea_loop（orchestrator:321）→ mea.run_mea_loop_core；仅由 auditor 的 verified findings 更新 TaskState OpenRSI 程序级岛模型（run_program_evolutionary_loop） IslandModel(n_islands)，branch gen{g}.isl{i} 四原子算子（纯函数，gated by assert_operator_inner_only 白名单）： Draft（seed）/ Improve（fit≥0.4）/ Debug（否则）/ Crossover（双亲） per-gen breed → 冠军送 layer_11 冻结审计 候选存档 EvolutionArchive(node_kind=program) ⚠ C1：interpreter 透传宿主 env → 沙箱待闭环 config 进化（run_evolutionary_loop，扁平种群） seed → select_parent → mutate → novelty_filter(≥0.92 拒) → 代冠军过冻结审计 预算三维硬停（exited_budget） max_seconds · max_capability_calls（_cap_call_counts，agent 调用也计数）· max_cost（cost_per_call）— 任一超额即停。 隔离不变量 / 护栏（强制） ① 审计只读策展输入，不读内循环事件日志（hypothesis/experience/lesson） ② 内循环 agent 禁止集 = {layer_11, layer_09}（assert_inner_capability_allowed 守卫 CLI/transport） ②' 算子白名单 = {inner, inner_program_evolution}（assert_operator_inner_only，fail-closed，P2-2 加固） ③ 累积对象必带 run_id 按 run 过滤；④ 终态必须为合法 WorkflowStatus 枚举（如 exited_budget） ⑤ 连续 REFINE streak≥3 → Restart（recoverable=False）抛弃无进展轨迹 ⑥ 程序候选送审计前显式剥离 feedback（P2-11）；⑦ MEA Auditor≠Executor 异模型（消除自确认）

④ 能力注册表、Agent 工具面、OpenRSI 算子与护栏

基础设施层 10 环节 + kaggle_eval + layer_11 审计 = 11 个注册能力。Agent 通过 PlatformSDK 调用 run_capability；内环工具白名单剔除外环/元循环能力。2026-08-04 新增 OpenRSI 四原子算子（纯函数，受算子白名单约束）。

⑤ 平台契约生成链（前后端单一事实来源）

pydantic 模型 → export_typescript.py → zod 类型。后端校验用 pydantic，前端用 contracts.ts（已与生成物同步并被 client.ts 引用）。OpenRSI 另有独立的零依赖 dojo 契约镜像（不进本导出链）。

不进 platform_contracts 导出链（独立本地重实现，vendor/openmle_dojo 仅参考）。

⑥ 前端组件树与数据获取

极简 SPA：React 18 + Vite + TS，零 UI/路由/状态库。App.tsx 自研路由 + 侧边栏；数据双通道 = REST 轮询（主）+ SSE（刷新触发器）。2026-08-04 起 EvolutionPanel 新增岛视图。

前端技术栈（零依赖）： react 18.3 / react-dom / zod（仅 3 个运行时依赖）。Vite 构建；CSS 变量手写暗色主题，无 UI 库、无图表库（对比条形图/树形/时间线均用 div+CSS 手工实现）。路由靠 App.tsx 的 useState 条件渲染，状态靠 props 上抛下传，无 Redux/Zustand。SSE 仅用于打断 3s 轮询立即重拉，真正数据来自 REST 轮询。

⑦ 持久化结构

两层持久化：控制平面用 JSON 文件（Repository，原子写 + 线程锁），双循环累积记忆用 SQLite（ResearchStateStore）。自定义任务独立 JSON。2026-08-04 起 evolution_candidates 支持 config/program 双粒度（岛模型分支）。
