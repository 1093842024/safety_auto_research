# 数据质量检查清单（Data Quality Checklist）

> 层⑤ 阶段 1「数据评估」的产出模板。每轮 badcase 回流/新数据接入必填，作为后续清洗与配比的依据。

## 1. 基础统计

- [ ] 总样本数、字段完整性（缺失率）
- [ ] 来源分布（old / new-badcase / 外部补充）
- [ ] 模态分布（文本/图像/多模态）
- [ ] 重复率：精确重复数、语义近邻重复数（embedding 近邻 top-k）

## 2. badcase 分型（回流场景必填）

| 错误类型 | 数量 | 占比 | 说明 |
|----------|------|------|------|
| 答非所问 / 意图误解 | | | |
| 格式违规（长度/关键词/结构） | | | |
| 事实/知识错误 | | | |
| 分布外（OOD） | | | |
| 安全越界（有害/越狱） | | | 走安全标签复核 |
| 其他 | | | |

→ 产出 `badcase_taxonomy.json`

## 3. 分布偏移度量

- [ ] badcase 分布 vs 训练集分布（类别占比差 / PSI / KS）
- [ ] 偏移最大的 Top-3 维度
- [ ] 训练集中样本稀少的"失败维度"（决定补数据优先级）

## 4. 标签质量

- [ ] 标签噪声率估计（小样本人工抽检，n≥100）
- [ ] 标签语义歧义点（需消歧/合并的类别）
- [ ] 稀有类（样本数 < 阈值，需合并或过采样）

## 5. 泄露与合规

- [ ] 训练/验证/测试是否有 group/时间重叠 → 复用层⑧ `data_leakage_agent`
- [ ] 是否含 PII / 违规样本 → 清洗前脱敏/过滤
- [ ] 安全相关标签是否人工复核

## 6. 质量门控阈值（建议默认值，可调）

| 指标 | 目标 | 失败动作 |
|------|------|----------|
| 精确重复率 | < 2% | 触发去重 |
| 语义重复率 | < 5% | 触发语义去重 |
| 标签噪声率 | < 5% | 触发重标注 |
| 泄露命中 | 0 | 阻断，重切分 |
| 标注一致性(κ) | ≥ 0.6 | 回流双标/人工 |

→ 产出 `data_quality_report.md`，门控通过方可进入阶段 2/4。
