# 数据质量与配比评测（Data Quality & Mixing Metrics）

> 层⑤ 的评测方式：在「数据评估/清洗/标注/配比」四阶段分别设定量化指标与门控，门控不通过不得进入下游。

## 1. 数据质量指标（阶段 1-2）

| 维度 | 指标 | 计算 | 建议阈值 |
|------|------|------|----------|
| 覆盖率 | 失败维度样本占比 | badcase 分型覆盖的训练集维度 | 缺口维度有补数计划 |
| 去重 | 精确/语义重复率 | 重复数 / 总数 | < 2% / < 5% |
| 标签噪声 | 噪声率 | 人工抽检错误标签 / n | < 5% |
| 分布偏移 | PSI / KS | badcase vs 训练集 | 偏移维度已标注 |
| 泄露 | 泄露命中数 | 层⑧ `data_leakage_agent` | 0（否则阻断重切分） |

## 2. 标签一致性（阶段 3）

- **Inter-annotator agreement**：Cohen's κ（双人）/ Fleiss' κ（多人）。
- 阈值：κ ≥ 0.6 通过；0.4–0.6 需仲裁；< 0.4 修订 schema 重标。
- **标签迁移正确性**：旧→新标签映射后，旧数据标签准确率抽检 ≥ 阈值。

## 3. 配比有效性（阶段 4）

- **保留率（Retention Ratio）** = 重训后 old-holdout 准确率 / 旧模型 old-holdout 准确率。
  - 门控：Retention Ratio ≥ `min_retention_ratio`（默认 0.9）。违反 → 配比判 0，回退调高 old 占比。
  - 直接复用 AutoLab `grpo_multisource` 的遗忘门控实现。
- **新能力补强**：badcase 验证集准确率较旧模型提升（Δ > 0，且统计显著）。
- **无灾难性遗忘**：所有旧能力维度无显著掉点（paired 检验 p > 0.05）。

## 4. 与下游评测的衔接

- 阶段 4 配比配置作为 **代码开发 ⑥** 训练代码的输入、`mixing_config.yaml`。
- 阶段 2 清洗数据集作为 **实验执行 ⑦** 重训输入。
- 若实验执行 ⑦ / 结果分析 ⑧ 反馈根因在数据（方差大/过拟合/偏移），经 **层⑨** 路由回本层对应子阶段重做。

## 5. 安全专项门控

- 敏感字段脱敏率 = 100%（清洗前）。
- 安全分级标签人工复核率 = 100%（`requires_human_review: true` 类）。
- 训练/验证/测试 group+时间隔离，泄露命中 = 0。
