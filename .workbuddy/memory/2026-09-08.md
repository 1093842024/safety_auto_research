## 坑（勿再踩）
- FastAPI route method 顺序不是字典序而是声明序（`@router.post` 写在前面就先 POST）。
- 调度器必须先 `start_workflow_run` 再 `run_capability`，否则 `ConflictError: stages can only be created for a running workflow`。
- `POLL_INTERVAL_SEC < 1.0` 会被 Pydantic `ge=1.0` 拒（422）。
- 测试 badcase CSV 必须用真 titanic schema（含 Name/Survived）否则 executor 在 `_build_xy` 失败
  （不增 trigger_count，scheduler 看似沉默）。
- `_SchedulerState` 必须**单实例**（loop 参数与 `_schedulers[run_id]` 共用同一对象），不然 loop
  写状态没人读。
